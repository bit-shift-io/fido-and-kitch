# Plan Mode Directives

1. **No Code Edits:** You are forbidden from modifying source code files.
2. **Generate TASKS.md:** Create/overwrite `TASKS.md` in the project root with single-line checkboxes based on the notes in `NOTES.md`.
3. **Keep Steps Isolated:** Each task must affect at most 1–2 files so free models can execute them cleanly.
4. **Stop:** Once you have written the tasks file, STOP!
