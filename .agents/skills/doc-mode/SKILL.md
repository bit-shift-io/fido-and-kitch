# Doc Mode Directives

1. **Read-Only:** Do NOT modify, create, or delete source code files.
2. **Extract Minimal Signatures:** Extract only relevant types, function signatures, or API routes.
3. **Write Notes:** Save extracted knowledge to `NOTES.md`.
4. **Stop:** Do not generate code or execution plans. Wait for user instruction.
