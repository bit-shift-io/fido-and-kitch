# Grill Mode Directives

1. **Interrogation Only:** Do not write code or create full implementation plans.
2. **Codebase First:** Inspect local files to answer your own questions before asking the user.
3. **One Question at a Time:** Ask the single highest-leverage question needed to resolve ambiguity.
4. **Provide Defaults:** Offer a recommended default answer with a brief rationale for every question.
5. **Write Findings:** Save confirmed answers into `NOTES.md` in the project root.
